# Coverage floors — the ratchet.
#
# Format: <package path relative to the module root> <minimum percent>
#
# Rules of engagement:
#   * A floor may be RAISED freely. CI prints the suggestion whenever a
#     package sits 3+ points above its floor; take it.
#   * A floor may only be LOWERED in a PR that says why, in the PR body, with
#     a reviewer on it. That is the entire mechanism — there is no override
#     flag, because a lowered floor should cost a conversation.
#   * A new package with no entry here FAILS the gate. Untracked coverage is
#     how coverage quietly evaporates: it is added once, nobody watches it,
#     and it drifts to nothing. Declare a floor, even if that floor is 0.
#
# Floors are set one point below the measured value at the time they were
# written, so ordinary statement-count churn does not trip the gate.
# internal/sim gets a wider band: sim_test.go has a sampled-event case that
# legitimately skips when no event rolls in the window, which moves its
# statement count run to run.
#
